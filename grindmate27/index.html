حدد تقييم اللاعب (Overall) ومركزه — بيرشحلك التطويرات اللي تناسبه ويوريك التقييم النهائي.

قائمة المراقبة تسجل السعر يوميًا بواسطة GitHub Action (من fut.gg). لضاية اللاعب: أضف رابط صفحة اللاعب في data/config.json.

تسريبات مجمعة من حسابات تويتر المشهورة (حديث Nitter RSS — كل 4 ساعات).

ربط تليجرام

  1. افتح @fc27rindMatebot واضغط Start.
  2. شغّل على جهازك: node scripts/link-telegram.mjs — يطبع كود Chat ID في ثانية.
  3. حط الرقم في data/config.json (telegram.chatId)، وفي GitHub بالـ vars اسم GRINDMATE_TG_CHAT، والتوكن في secrets اسمه GRINDMATE_TG_TOKEN.

مصادر البيانات

  • الأوبجكتيف والتطويرات: FUT.GG — تحديث تلقائي كل 4 ساعات بواسطة GitHub Action.
  • التسريبات: Nitter RSS لحسابات مختارة — لو فشلت القنوات تظهر رسالة «حاول لاحقًا».
  • الأسعار: لقطات يومية لصفحة اللاعب على FUT.GG — تجمع لتاريخك في data/prices.json.

المشروع مفتوح: صفحة + Action + بوت — كل مجاني على GitHub.
