# التحضير الآلي — تطبيق أندرويد

تطبيق بسيط يفتح موقع «التحضير الآلي» ومنصة نور في شاشتين، ويحقن أداة اللصق تلقائيًا (بدون Tampermonkey).
الأداة نفسها تُجلب من الموقع عند كل تشغيل، فتصل التحديثات بدون إصدار تطبيق جديد.
التطبيق لا يضغط حفظ أو نشر في نور أبدًا.

البناء يتم تلقائيًا عبر GitHub Actions، والملف الناتج يُنشر في فرع `dist`.
